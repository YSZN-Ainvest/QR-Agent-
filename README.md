# 股票量价（PV）研究任务集

## 项目简介

本项目收录了 **150 道股票量价（Price-Volume, PV）研究任务**，以及一份用于指导任务设计、生成和扩展的规范文档。

项目旨在构建一套具有真实量化研究价值、问题类型丰富、适合交由 AI Agent 独立完成的研究任务集合。

这些任务以量化研究人员的实际需求为出发点，覆盖金融现象探索、因子研究、机器学习、策略优化及风险管理等方向。

与传统的算法题或工程开发任务不同，本项目强调：

- **问题驱动**：从实际金融现象、研究疑惑或投资决策需求出发。
- **研究开放性**：明确研究目标，但不提前规定完整的技术方案和实验流程。
- **结果可验证**：鼓励利用历史数据、统计分析和回测评估研究假设。
- **决策导向**：不仅关注统计显著性，也关注实际投资价值及收益、风险、成本之间的取舍。
- **结论中立**：允许研究假设不成立、复杂方法没有改善或候选因子缺乏实际价值。

本项目既可以作为量化研究 Agent 的任务来源，也可以用于评估 AI 系统开展自主金融研究的能力。
